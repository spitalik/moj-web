Ako získať API kľúč pre Parley

Na claude.ai odpovedá tutor cez Claude a nič nastavovať netreba. Ak Parley otvoríte inde, napríklad na vlastnom webe alebo v Chrome na telefóne, potrebuje vlastný API kľúč od DeepSeek alebo OpenAI. Kľúč je ako heslo, ktorým Parley platí za odpovede z vášho účtu.

Ktorú službu vybrať

DeepSeek alebo OpenAI?

  • DeepSeek je výrazne lacnejší. Na precvičovanie konverzácie úplne stačí a jeden rozhovor stojí zlomok centu.
  • OpenAI (firma za ChatGPT) je drahší, ale známejší a často trochu prirodzenejší v angličtine.

Obe služby sa platia vopred kreditom. Ceny sa menia, aktuálne nájdete na stránke poskytovateľa v časti Pricing.

Možnosť 1

DeepSeek

  1. Otvorte platform.deepseek.com a zaregistrujte sa e-mailom alebo účtom Google.
  2. V menu vľavo otvorte Top up a dobite malý kredit, napríklad 2 až 5 USD. Bez kreditu kľúč nefunguje.
  3. Otvorte API keys a kliknite na Create new API key. Pomenujte ho napríklad „Parley“.
  4. Kľúč začína na sk-. Hneď ho skopírujte, celý sa zobrazí len raz.
  5. V Parley kliknite na Nastavenia, vložte kľúč do poľa DeepSeek → API kľúč a kliknite na Uložiť. Model nechajte deepseek-chat.
Možnosť 2

OpenAI (ChatGPT)

Predplatné ChatGPT Plus sa na API nevzťahuje. API je samostatná služba s vlastným kreditom.

  1. Otvorte platform.openai.com a prihláste sa. Funguje aj rovnaký účet ako pre ChatGPT.
  2. V nastaveniach otvorte Billing, pridajte platobnú kartu a kúpte kredit. Najmenšia suma býva 5 USD.
  3. Odporúčam v časti Limits nastaviť mesačný limit míňania, napríklad 5 USD.
  4. Otvorte platform.openai.com/api-keys a kliknite na Create new secret key.
  5. Kľúč začína na sk-. Skopírujte ho hneď, druhýkrát sa už nezobrazí.
  6. V Parley kliknite na Nastavenia, vložte kľúč do poľa OpenAI → API kľúč a kliknite na Uložiť. Model môžete nechať predvolený. Ak ho OpenAI už neponúka, zadajte názov aktuálneho lacného modelu z ich stránky Models.
Na telefóne

Postup na Androide

  1. Stránku poskytovateľa otvorte v Chrome a vytvorte kľúč podľa návodu vyššie.
  2. Kľúč skopírujte podržaním prsta na ňom alebo tlačidlom Copy.
  3. Otvorte Parley v Chrome, ťuknite na Nastavenia, podržte prst v poli API kľúč a zvoľte Prilepiť.
  4. Cez ponuku Chrome ⋮ → Pridať na plochu si môžete Parley otvárať ako aplikáciu.
Bezpečnosť

Ako s kľúčom zaobchádzať

  • Parley si kľúč uloží len v prehliadači na tomto zariadení. Posiela ho iba priamo službe DeepSeek alebo OpenAI, nikam inam.
  • Kľúč nikomu neposielajte a nevkladajte ho do kódu stránky ani na GitHub. Ktokoľvek s kľúčom by mohol míňať váš kredit.
  • Na cudzom alebo zdieľanom počítači kľúč po použití vymažte v Nastaveniach.
  • Ak kľúč unikne, zmažte ho na stránke poskytovateľa a vytvorte nový.
